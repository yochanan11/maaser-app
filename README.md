# מעשר

אפליקציית PWA לניהול מעשרות: הכנסות, מעשר שניתן והוראות קבע. עברית, RTL, לוח בקרה עם גרפים.

## הרצה מקומית

```bash
npm install
npm start
```

נפתח ב-http://localhost:3000. הסיסמה המקומית היא `dev`, והנתונים נשמרים בקובץ `data.db` (SQLite).

## פריסה ב-Render

1. מעלים את התיקייה ל-GitHub ויוצרים ב-Render **Web Service** (Node). Build: `npm install`, Start: `npm start`.
2. יוצרים **PostgreSQL** ב-Render ומעתיקים את ה-Internal Database URL.
3. משתני סביבה לשירות:
   - `DATABASE_URL` - הכתובת של ה-Postgres
   - `APP_PASSWORD` - הסיסמה שלך לכניסה (חובה, ארוכה)
   - `NODE_ENV=production`
4. בטלפון (אייפון): פותחים את הכתובת ב-Safari, שיתוף, "הוסף למסך הבית".

## איך זה עובד

- הכנסה: סכום נטו ואחוז מעשר (ברירת מחדל 10%, 0 = פטור).
- יתרה = סך המעשר הנדרש פחות סך מה שניתן. מצטבר, בלי איפוס חודשי.
- הוראת קבע נוספת אוטומטית כל חודש ביום שהוגדר (בחודש קצר, ביום האחרון). אפשר להשהות בלי למחוק.
